# Comparison and analysis of segmentation models for pet recognition
LELEC2885 - Image processing and computer vision

*Segmentation models are essential for image-based pet recognition, with applications in wildlife detection for endangered species. This study evaluates U-Net and PSPNet on The Oxford-IIIT Pet Dataset, comparing their segmentation performance and uncertainty estimation. While segmentation models are widely used, comparative analysis for pet recognition and uncertainty estimation remain underexplored. We trained both models on an NVIDIA GTX1070 Ti and assessed them qualitatively and quantitatively. PSPNet outperforms U-Net in accuracy but is more computationally intensive. Uncertainty analysis shows PSPNet’s sensitivity to pixel-based transformations (e.g., brightness, noise) but robustness to geometric changes (e.g., rotations, flips). Findings suggest PSPNet is well-suited for pet segmentation but requires adaptive thresholding. Future work should explore data augmentation, hyperparameter tuning, and additional models like Mask R-CNN and DeepLabV3+.*
